# Чайный путь 2: для разработчиков

Сборка и устройство проекта. Описание для пользователей — в README.md.

## Что нового по сравнению с первой версией

- **Несколько таймеров одновременно.** Можно заваривать сразу несколько чаёв и кофе: у каждого свой таймер, свой пролив, свои кнопки. Вкладка «Таймеры» со счётчиком работающих.
- **Таймеры не пропадают** при переходе между экранами и при перезапуске приложения, а уведомление приходит на каждый таймер отдельно.
- **Свой звук таймера:** Гонг, Колокольчик, Мелодия, Сигнал, системный или без звука. Звук можно задать в настройках (по умолчанию), для отдельного сорта и для отдельного запущенного таймера. При выборе звук проигрывается.
- **Кастомизация таймера:** своё название («Чашка для мамы»), своё время проливов, правка ±10 секунд, быстрый свой таймер (кнопка ＋ на вкладке «Таймеры»).

Из первой версии остались каталог сортов (8 чаёв, 5 способов кофе), добавление своих сортов, 3 темы, °C/°F, вибрация.

## Стек

React Native + Expo (SDK 52), TypeScript, expo-notifications (локальные уведомления со своими звуками), expo-av (прослушивание звуков), AsyncStorage.

## Как устроено

- `src/timers.tsx` — общее хранилище таймеров: список, тик каждые 250 мс, остаток считается по времени окончания, поэтому таймер не отстаёт в фоне. Состояние сохраняется в AsyncStorage.
- `src/notifications.ts` — на каждый звук создаётся свой канал уведомлений (на Android звук задаётся каналом).
- `assets/sounds/` — звуки `.wav`, подключаются плагином expo-notifications при сборке.

## Запуск и сборка APK

```bash
npm install
npx expo start      # разработка (Expo Go; звуки уведомлений лучше проверять на APK)
```

APK собирает GitHub Actions: запушьте проект в `main`, откройте Actions → Build APK → Artifacts → `chai-puti-2-apk`.
Для Releases: `git tag v2.0.0 && git push origin v2.0.0`.

Локально (нужны JDK 17 и Android SDK): `npx expo prebuild --platform android`, затем `cd android && ./gradlew assembleRelease`.
